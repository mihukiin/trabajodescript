Trabajo Práctico 1 - PowerShell

Módulo: Programación para Seguridad Informática

Docente: Lic. Carlos Pacheco

Tema: Comandos básicos de auditoría con PowerShell y CMD

1. Consignas

Desarrollar un script en PowerShell que obtenga:

  1. Versión de PowerShell.
  2. Configuración de permisividad (Execution Policy).
  3. Edición del sistema operativo.
  4. Información completa del equipo mediante el comando adecuado del símbolo del sistema (CMD).

2. Script Implementado (info_sistema.ps1)

# Trabajo Practico 1 - PowerShell
# Modulo: Programacion para Seguridad Informatica
# Docente: Lic. Carlos Pacheco

# 1. Version de PowerShell
Write-Host "--- 1. VERSION DE POWERSHELL ---"
$PSVersionTable.PSVersion

# 2. Configuracion de permisividad (Execution Policy)
Write-Host "`n--- 2. PERMISIVIDAD (EXECUTION POLICY) ---"
Get-ExecutionPolicy -List

# 3. Informacion de la edicion del Sistema Operativo
Write-Host "`n--- 3. EDICION DEL SISTEMA OPERATIVO ---"
Get-CimInstance Win32_OperatingSystem | Select-Object Caption, Version, OSArchitecture, BuildNumber

# 4. Informacion completa de la PC (comando del simbolo del sistema)
Write-Host "`n--- 4. INFORMACION COMPLETA DE LA PC (CMD) ---"
systeminfo

3. Comandos Utilizados y Justificación

Ítem Comando Descripción
1. Versión $PSVersionTable.PSVersion Variable interna que retorna la versión del motor de PowerShell instalada.
2. Permisividad Get-ExecutionPolicy -List Muestra las directivas de ejecución aplicadas por cada alcance (Machine, User, Process, etc.).
3. Sistema Operativo Get-CimInstance Win32_OperatingSystem Consulta WMI/CIM nativa para ver nombre de la edición, compilación y arquitectura.
4. Info PC systeminfo Comando del símbolo del sistema que recopila hardware, BIOS, memoria RAM y parches.
